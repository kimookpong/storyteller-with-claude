## 3. แนวคิด: ค่าตั้งต้นที่เดียว แล้วคำนวณที่เหลือ

```
presets/                         ← ของช่อง (ใช้ซ้ำทุกโปรเจกต์)
  formats/  landscape-16x9 · shorts-9x16
  styles/   kurzgesagt-vox · archive-doc · map-explainer
  voices/   friend-sleepy-male · friend-bright-female · doc-narrator
projects/<slug>/settings.json    ← เลือก preset + override ต่อโปรเจกต์
```

```json
{
  "format": "landscape-16x9",
  "style": "kurzgesagt-vox",
  "voice": "friend-sleepy-male",
  "targetSec": 180,
  "overrides": { "style.eras": ["present", "medieval", "early-modern", "1800s"], "subtitles": true }
}
```

ทุกอย่างอ่านจากไฟล์นี้: rules เขียนเป็น “ดูค่าใน settings” · `validate`, `resolve.ts`, `tts.py`, `qa.mjs`, หน้า UI คำนวณเกณฑ์จากสูตรเดียวกัน (`app/lib/budget.mjs` + ฝั่ง TS ใช้ไฟล์ JSON เดียวกัน)

## 4. แกนที่ 1 — แนวทางวิดีโอ (style preset)

style preset = ภาษาภาพทั้งชุด ไม่ใช่แค่สี

| ส่วนประกอบ | ค่าใน preset | ปัจจุบัน (kurzgesagt-vox) |
|---|---|---|
| สัดส่วนชนิดช็อต | parallax / vector / collage / data / title (%) | 30–40 / ~30 / 20–30 / 10–15 |
| จังหวะภาพ | วินาทีเฉลี่ยต่อช็อต, สูงสุด | 3–5 / 8 |
| ยุคที่ใช้ได้ | จากชุดที่ **โค้ดรองรับจริง** | present, medieval, early-modern, 1800s |
| palette + font | token | tokens.ts, Kanit / IBM Plex / Mali |
| texture | ความแรงต่อยุค | eras.ts |
| character anchor | asset + props | bean + หมวกตามยุค |
| subtitle | เปิด/ปิด, ขนาด | เปิด 40px |

**preset ที่ทำได้ด้วยโค้ดและ asset ที่มีอยู่** (ไม่ต้องสร้างระบบใหม่):
- `kurzgesagt-vox` — แบบปัจจุบัน
- `archive-doc` — collage/ภาพเอกสาร 50%+, กล้อง drift ช้า, texture แรงขึ้น, ช็อตเฉลี่ย 5–7 วิ (เหมาะเรื่องประวัติศาสตร์ยาว ๆ ต้องการ asset collage เพิ่ม)
- `map-explainer` — data/map 35–45% (d3-geo มีแล้ว) สำหรับเรื่องการค้า เส้นทาง ภูมิรัฐศาสตร์

**ช่องโหว่ที่ต้องแก้ก่อนเปิดให้เลือกยุค:** `eras.ts` + `transitions.tsx` ต้องเพิ่ม `ancient`, `early-1900s`, `mid-century` ฯลฯ ให้ครบตาม rule 05 หรือไม่ก็ตัด rule 05 ให้เหลือเฉพาะที่รองรับ — validate ควรเช็กว่า era ใน shots.json มีใน `eras.ts`

**Format (16:9 vs 9:16 Shorts) ไม่ใช่แค่สวิตช์:** ตำแหน่ง layer/ข้อความใน shots.json เป็นพิกเซลของ 1920×1080 · safe area, ซับ, ปก ต่างกันหมด → ทำเป็น format แยกที่ Claude ออกแบบช็อตใหม่ (ไม่ใช่แปลงอัตโนมัติ) และเลื่อนไปทำหลังระบบ settings หลักเสร็จ

## 5. แกนที่ 2 — ความยาวคลิป

ใส่ `targetSec` ตัวเดียว ที่เหลือคำนวณ (อัตราพูด r มาจาก voice preset):

```
speechSec   ≈ targetSec × 0.95           (5% = head/tail/transition จาก coffee-world)
charsMax    ≈ speechSec × r              (r = 10.2 สำหรับ Umbriel)
charsMin    ≈ charsMax × 0.88
shots       ≈ targetSec / 4.5 … targetSec / 3.6
reveals     ≈ targetSec / 35             (mini-reveal ทุก 30–40 วิ ตาม rule 02)
ยอมรับ      = targetSec ± 8%
```

| ความยาว | ตัวอักษร | ช็อต | mini-reveal | โครงเรื่อง |
|---|---|---|---|---|
| 1:00 (Shorts) | 510–580 | 15–18 (เฉลี่ย ~3.5 วิ) | 1–2 | hook → 1 reveal → payoff (ไม่มี act, ≤ 2 ยุค) |
| 3:00 (ปัจจุบัน) | 1,540–1,745 | 40–50 | 5 | 7 beat ตาม rule 02 |
| 5:00 | 2,560–2,910 | 67–83 | 8–9 | 7 beat แต่ act 2–3 แตกเป็น 2 ช่วงย่อย |
| 8:00 | 4,100–4,655 | 107–133 | 13–14 | แบ่ง **บท (chapter)** 3–4 บท บทละ 90–120 วิ แต่ละบทมี hook ย่อย |
| 10:00 | 5,120–5,820 | 133–167 | 17 | 4–5 บท · ≤ 4 ยุคทั้งเรื่อง |

**Beat ต้องคำนวณแบบผสม** ไม่ใช่คูณสัดส่วนตรง ๆ: hook คงที่ 10–15 วิ และ outro 5–10 วิ ทุกความยาว (คนตัดสินใจดูต่อใน 15 วิแรกเท่าเดิม) · ส่วนกลางแบ่งตามสัดส่วน setup 10% / acts 75% / payoff 12%

**ผลข้างเคียงที่ต้องบอกผู้ใช้ตอนเลือก:**
- ค่า TTS และเวลา render โตตามความยาวแบบเส้นตรง
- 8–10 นาทีต้องใช้ช็อต ~3 เท่า แต่คลัง asset มี ~40 ชิ้น → ภาพซ้ำเยอะ ต้องวางแผน asset (stage 6) จริงจัง
- rule 02 “≤ 4 ยุค” และ “1 metaphor หลัก” ยังใช้ได้ แต่คลิปยาวควรมีบทสรุปกลางเรื่อง

## 6. แกนที่ 3 — เสียงพากย์ (voice preset)

แยก 3 ชั้นที่ตอนนี้ปนกันอยู่:

| ชั้น | ใครใช้ | ค่า |
|---|---|---|
| **บุคลิก (persona)** | Claude ตอนเขียนบท + validate | เพศ/อายุ, สรรพนาม (เรา/ผม/ฉัน), คำลงท้ายที่ใช้ได้ (นะ อะ / ค่ะ นะคะ / ไม่มี), ระดับภาษา, คำต้องห้าม, คำที่จำกัดจำนวน (เช่น “ง่วง” ≤ 1), ใช้ “ครับ/ค่ะ” ได้ที่ไหน |
| **เสียง (render)** | `tts.py` | model, voice, style prompt, ช่องหยุดระหว่างช่วง, ช่องหยุดย่อหน้า |
| **อัตราพูด** | สูตรความยาว + `resolve.ts` | r (ตัว/วินาที) — **วัดจาก audition จริง** ไม่ใช่เดา |

**preset ตั้งต้นที่แนะนำ:**

| preset | บุคลิก | TTS | r (ประมาณ ต้องวัด) |
|---|---|---|---|
| `friend-sleepy-male` | ปัจจุบัน: เพื่อนชายเล่าตอนดึก, “เรา”, นะ/อะ/แหละ, ห้ามครับกลางเรื่อง, ง่วง ≤ 1 | Gemini · Umbriel + style เดิม | 10.2 (วัดแล้ว) |
| `friend-bright-female` | เพื่อนหญิงสดใส, “เรา”, นะ/อะ/เนอะ, “ค่ะ” เฉพาะ outro | Gemini · เสียงหญิง (เลือกจาก audition) | ~11 |
| `doc-narrator` | ผู้บรรยายสารคดี สุภาพกึ่งทางการ, ไม่มีคำลงท้าย, อนุญาตภาษาเขียนบางคำ | Gemini · เสียงทุ้ม + style จริงจัง ช้า | ~9 |

**ข้อควรระวัง**
- `validate.mjs` ต้องอ่านกฎจาก persona (ตอนนี้ฝังกฎของเพื่อนชายไว้) ไม่งั้นเปลี่ยนเสียงแล้ว validate ผิด
- เปลี่ยน voice/style = cache key เปลี่ยน → **สร้างเสียงใหม่ทั้งเรื่อง** (เสียเงินเต็ม) — UI ต้องเตือนและให้ audition ก่อน
- เปลี่ยน persona หลังอนุมัติบท = บทต้องเขียนใหม่ (คำลงท้าย/สรรพนามเปลี่ยน)
- **พจนานุกรมการอ่าน** (`voTTS`) ตอนนี้แก้มือทีละซีน → ควรมี `presets/lexicon.json` ของช่อง (เช่น Lloyd's → ลอยด์ส, ตัวเลขปี) ให้ Claude ใช้ซ้ำ

## 7. ลำดับการล็อกค่า (ใช้ระบบ “ล้าสมัย” ที่มีอยู่)

| ค่า | เปลี่ยนได้ถึง | ถ้าเปลี่ยนหลังจากนั้น → stage ที่ล้าสมัย |
|---|---|---|
| format | ก่อน stage 5 (Shot list) | shots, voice, preview, qa, cover |
| targetSec | ก่อน stage 3 (Beat sheet) | beats, script, shots, voice, … |
| persona | ก่อน stage 4 (บท) | script, shots, voice, … |
| TTS voice / style | ก่อน stage 7 | voice, preview, qa |
| style preset | ก่อน stage 5 | shots, preview, qa, cover |

ทำได้โดยใส่ hash ของ `settings.json` ส่วนที่เกี่ยวข้องเข้าไปใน fingerprint ของแต่ละ stage (`app/lib/project.mjs`)

## 8. UI ที่ต้องเพิ่ม
- **ฟอร์มเริ่มเรื่องใหม่:** เลือก format · ความยาว (1/3/5/8/10 นาที หรือกรอกเอง) · style · voice → แสดงงบที่คำนวณได้ทันที (ตัวอักษร/ช็อต/ซีน/ค่าเสียงโดยประมาณ)
- **หน้า Settings (stage 0):** แก้ค่าได้พร้อมเตือนว่าจะทำให้ stage ไหนล้าสมัย · ปุ่ม audition เสียง (ใช้ `tts.py --audition` ที่มีอยู่) แล้ววัด r อัตโนมัติ
- มิเตอร์งบตัวอักษร / งบเสียง / QA ความยาว อ่านเกณฑ์จาก settings แทนเลข 3 นาที

## 9. แผนทำ (เสนอ)
1. **Settings core:** `settings.json` + `presets/` (3 voice, 1–3 style, 1 format) + `budget` สูตรเดียว → แก้ validate, resolve.ts, tts.py, qa.mjs, app.js ให้อ่านค่า · coffee-world ได้ settings = ค่าปัจจุบัน (ต้องได้ผลเหมือนเดิมเป๊ะ)
2. **Rules เป็นพารามิเตอร์:** 01/02/03 เปลี่ยนตัวเลขตายตัวเป็น “ดู settings” + ตาราง beat ตามช่วงความยาว · persona ย้ายไป `presets/voices/*.md`
3. **UI:** ฟอร์มใหม่ + หน้า Settings + audition/วัดอัตราพูด
4. **ยุคเพิ่ม** ใน eras.ts ตามที่เรื่องถัดไปต้องใช้
5. **Shorts 9:16** เป็นเฟสแยก

## 10. เรื่องที่ต้องตัดสินใจ
- ช่องจะมี **เสียงเดียวเป็นเอกลักษณ์** (preset เดียว ปรับได้น้อย) หรือ **หลายเสียงตามเรื่อง**?
- ความยาวหลักของช่องคือเท่าไร — ถ้ายังเน้น 3–5 นาที ให้ทำข้อ 1–3 ก่อน, chapter สำหรับ 8–10 นาทีทำทีหลัง
- ต้องการ Shorts ไหม (ถ้าต้องการ แนะนำให้ Shorts ตัดจากคลิปหลักเป็นช็อตแนวตั้งที่ออกแบบใหม่ ไม่ใช่ crop)
