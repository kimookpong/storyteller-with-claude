# Analysis — ทำไม RULE ถึงออกมาแบบนี้

## 1. สเปกที่ได้รับ
- Infographic ~3 นาที · Kurzgesagt × Vox Collage · texture เปลี่ยนตามยุค · 2.5D parallax + DOF
- บรรยายไทย เพื่อนเล่าให้เพื่อนฟัง ผู้ชาย เป็นมิตร ง่วง ๆ นิดนึง
- Output: บท + shot list และโค้ด Remotion

## 2. จุดตึง (tension) ที่ RULE ต้องแก้

| ปัญหา | ความเสี่ยง | ทางแก้ใน RULE |
|------|----------|--------------|
| เสียงง่วง/ช้า vs Kurzgesagt ที่ภาพเร็ว | ทั้งเสียงและภาพช้า → คนดูง่วงตาม | "เสียงชิล ภาพมีพลัง": ช็อตเฉลี่ย 3–5s, ห้ามภาพนิ่ง >1s, mini-reveal ทุก 30–40s (01, 02) |
| สองสไตล์ในเฟรมเดียว | ภาพรก ไม่รู้จะมองตรงไหน | แบ่งหน้าที่: vector = กลไก/ปัจจุบัน, collage = อดีต/หลักฐาน; 1 เฟรม 1 พระเอก; DOF ช่วยแยก (04, 06) |
| Texture เปลี่ยนตามยุค | ทั้งเรื่องไม่มีเอกลักษณ์เดียว | Character anchor + accent-2 คงที่, texture หนักที่ BG เบาที่ subject, จำกัด ≤4 ยุค (04, 05) |
| "ง่วง" ตีความผิด | ผู้เล่าฟังดูเบื่อ/ไม่แคร์ หรือพูดว่าง่วงบ่อยจนน่ารำคาญ | นิยามว่า "ง่วง" = จังหวะ/น้ำเสียง ไม่ใช่เนื้อหา, คำว่าง่วง ≤1 ครั้ง (03) |
| ภาษาไทยนับคำยาก | บทยาวเกิน 3 นาทีโดยไม่รู้ตัว | งบเป็นตัวอักษร (1,500–1,800) + ความจริงสุดท้ายคือไฟล์เสียง (01) |
| ภาษาพูดเกินไป | ฟังไม่เป็นมืออาชีพ/คำลงท้ายรก | จำกัดคำลงท้าย/filler, ห้ามกู-มึง, ห้ามครับกลางเรื่อง (03) |
| สระ/วรรณยุกต์ไทยบนจอ | โดนตัด, ตัดบรรทัดกลางคำ | line-height ≥1.45, Intl.Segmenter (07) |
| Parallax พังได้ง่าย | ขอบภาพโผล่, เมา, สูตรกล้องไม่เหมือนกันแต่ละช็อต | สูตรกล้องเดียว, asset เผื่อขอบ 15–20%, ≤3 ช็อต parallax ติดกัน (06, 10) |
| Timing บท ↔ ภาพ | hardcode แล้วพังทุกครั้งที่อัดเสียงใหม่ | cue marker `[#shotId]` ใน VO + calculateMetadata จากไฟล์เสียง (09, 10) |
| ความถูกต้อง | Claude แต่งตัวเลขเอง | facts.md + sourceRef บังคับ + validate อัตโนมัติ (00, 07, 11) |
| ลิขสิทธิ์สไตล์ | ลอกตัวละคร/กราฟิกของช่องต้นแบบ | เอาแค่หลักการ ออกแบบ anchor เอง (04) |

## 3. การตัดสินใจหลัก
1. **`shots.json` เป็นสัญญากลาง** — บทกับโค้ดคุยกันผ่านไฟล์เดียว ทำให้แก้บทแล้ว regenerate ได้โดยไม่แตะโค้ด
2. **1 ไฟล์เสียงต่อ scene** — อัดใหม่เฉพาะซีนได้, timing คำนวณใหม่อัตโนมัติ
3. **Placeholder-first** — ตรวจจังหวะ/กล้องได้ก่อนมีภาพจริง ลดงานทิ้ง
4. **Checkpoint 4 จุด** (brief, beats, script, ก่อน render) — จุดที่แก้แล้วแพงถ้าผิด
