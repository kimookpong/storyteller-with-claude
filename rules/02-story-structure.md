# 02 · Story Structure

> เวลา/ตัวอักษร/ช็อตของแต่ละ beat **คำนวณจาก settings** — ใช้ตารางจาก `npm run budget -- <slug>` เสมอ
> โครงเรื่องเลือกตามความยาว: **คลิปสั้นจบในตัว** (≤ 1:15) · **7 beat** (1:15–7:00) · **แบ่งบท / chapter** (≥ 7:00)

## 7 beat (โครงหลัก)
hook และ outro มีความยาวเกือบคงที่ทุกความยาว (คนตัดสินใจดูต่อใน 10–15 วิแรกเท่าเดิม) · ส่วนกลางแบ่งตามสัดส่วน

| Beat | สัดส่วน / เวลา | ช็อต (ตัวอย่าง 3:00) | หน้าที่ |
|------|------|------|--------|
| 1. Hook | 8–15 วิ (≈ 6.7% ของ T) | 3–4 | คำถาม/ความขัดแย้งที่ทำให้ต้องดูต่อ + ภาพที่แรงที่สุดของเรื่อง (ต้องเป็น 2.5D parallax + DOF) |
| 2. Setup | 11% ของส่วนกลาง | 4–5 | ทำไมเรื่องนี้เกี่ยวกับคนดู, วางกรอบว่าจะพาไปดูอะไร |
| 3. Act 1 — ต้นเรื่อง | 24.5% | 9–11 | อธิบายพื้นฐาน, มักเป็นยุคแรกสุด (texture ย้อนยุค) |
| 4. Act 2 — มันซับซ้อนกว่านั้น | 27.6% | 10–13 | เดินทางข้ามยุค/ขยายสเกล, มี complication 1 อย่าง |
| 5. Act 3 — จุดพลิก | 24.5% | 9–11 | insight หลัก + **data moment ใหญ่ 1 ครั้ง** |
| 6. Payoff | 12.4% | 4–6 | ตอบคำถามจาก Hook, โยงกลับมาหาคนดู |
| 7. Outro | 4–10 วิ | 1–2 | ประโยคปิดนุ่ม ๆ แบบเพื่อนบอกลา ไม่ยัด CTA ยาว |

ที่ 3:00 ได้ timecode เดิม: 0:12 · 0:30 · 1:10 · 1:55 · 2:35 · 2:55 · 3:00

## คลิปสั้นจบในตัว (≤ 1:15 · TikTok / Reels / Shorts)
ใช้คู่กับ format `portrait-9x16` + style `shorts-punch` (+ เสียง `fast-hype` ถ้าอยากได้จังหวะรัว) · ตาราง beat จริงอยู่ใน `npm run budget -- <slug>`

| ความยาว | beat | หน้าที่ |
|---|---|---|
| 0:30 | hook 3 วิ → act1 → act2 → payoff → outro 2 วิ | reveal 2 ครั้ง |
| 1:00 | hook 3 วิ → setup → act1 → act2 → act3 → payoff → outro 3 วิ | reveal 3 ครั้ง |

- **1 คลิป = 1 คำถาม ตอบจบในคลิป** · ประโยคแรก (≤ 3 วิ) คือคำถาม/ตัวเลขที่แรงที่สุด · **ภาพแรกขยับตั้งแต่เฟรมแรก**
- ห้ามทักทาย / "ติดตาม" / "กดไลก์" / "ตอนหน้า" (validate เตือน) · ตัวเลข ≤ 3 ตัวต่อ 30 วิ · ≤ 2 ยุค
- **outro = loop line**: ประโยคสุดท้ายโยงกลับไปประโยคแรก ให้คนดูวนซ้ำ
- ภาพ/ข้อความอยู่ใน safe zone แนวตั้ง: x 90–930, y 160–1500 (ล่างสุด 420px เป็นพื้นที่ปุ่ม/คำบรรยายของ TikTok) · ซับอยู่ที่ y ≈ 1300 → ตัวเลข/ป้ายวางช่วง y 250–1150
- แตกจากเรื่องยาว: สร้างโปรเจกต์ใหม่ + เลือก "แตกจากโปรเจกต์" ใน HistoryTeller (คัดลอก facts.md, ใช้ asset ร่วม, **เขียนบท/ช็อตใหม่** — ห้ามครอปจากคลิป 16:9)

## แบ่งบท / chapter (≥ 7:00)
- Act 1–3 แตกเป็น **3–5 บท** บทละ 90–120 วิ (จำนวนบทอยู่ในผล `npm run budget`)
- แต่ละบทมี **hook ย่อย** (คำถามของบทนั้น) ตอนต้น และ **reveal** ตอนท้าย
- ระหว่างบทมีประโยคสรุปสั้น ๆ 1 ประโยค ("สรุปถึงตรงนี้คือ…") กันคนหลง
- ใน beats.md ระบุ `chapter` ของแต่ละ scene; `beat` ใน shots.json ยังใช้ act1/act2/act3

## กติกา (ทุกความยาว)
- Hook ห้ามขึ้นต้นด้วย "สวัสดี" / แนะนำช่อง — เข้าเรื่องเลย
- คำถามใน Hook ต้องถูกตอบใน Payoff (ตรวจได้)
- ทุก 30–40 วินาทีต้องมี "mini-reveal" (ตัวเลขน่าตกใจ, เปรียบเทียบสเกล, มุกเล็ก ๆ) กันคนเลื่อนหนี — จำนวนขั้นต่ำอยู่ใน budget
- ข้ามยุคต้องมีประโยคเชื่อมเวลาชัดเจน ("ย้อนไปอีกสักสองร้อยปี...") และมี texture transition (ดู 05)
- เรื่องหนึ่งใช้ยุคไม่เกิน `style.maxEras` (ค่าเริ่ม 4) และต้องเป็นยุคที่ `src/era/eras.ts` รองรับ (validate ตรวจ)
- เลือก **1 metaphor หลัก** ใช้ต่อเนื่องทั้งเรื่อง (เช่น "เมืองคือสิ่งมีชีวิต") แทนการเปลี่ยน metaphor ทุกซีน
