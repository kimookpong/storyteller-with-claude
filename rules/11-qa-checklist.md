# 11 · QA Checklist (ต้องผ่านทั้งหมดก่อนส่ง)

## เรื่อง & ข้อมูล
- [ ] Hook ถูกตอบใน Payoff
- [ ] ทุกตัวเลขมี sourceRef และตรงกับ facts.md
- [ ] มี mini-reveal ทุก 30–40 วินาที, มี data moment ใหญ่ 1 ครั้ง

## เสียงบรรยาย
- [ ] ความยาวรวมอยู่ในช่วงที่ยอมรับของ settings (targetSec ± 8%, วัดจากไฟล์จริง)
- [ ] ไม่มีคำต้องห้าม / คำสุภาพกลางเรื่อง / คำจำกัดจำนวน ตาม persona ของ voice preset
- [ ] คำลงท้าย ≤ 1 ต่อประโยค
- [ ] อ่านออกเสียงแล้วเหมือนคนคุยกันจริง (ลองอ่าน 3 ประโยคสุ่ม)

## ภาพ
- [ ] จำนวนช็อตตามงบ, ไม่มีช็อตนิ่งสนิท > 1s
- [ ] สัดส่วน parallax ตาม style, ไม่ติดกันเกิน `maxParallaxRun`
- [ ] ทุกเฟรมมีพระเอกสไตล์เดียว, accent ≤ 2 สี
- [ ] ยุคเปลี่ยนตรงประโยคเชื่อมเวลา และมี transition
- [ ] ตัวหนังสือ/ตัวเลข/subtitle ไม่เบลอ ไม่โดน texture, สระไทยไม่โดนตัด
- [ ] ขอบ layer ไม่โผล่ตอนกล้องขยับ
- [ ] เปิดดูแบบปิดเสียงแล้วยังเข้าใจเรื่องคร่าว ๆ

## เทคนิค
- [ ] `npm run validate` ผ่าน
- [ ] −14 LUFS, peak ≤ −1 dBTP, VO ไม่จมเพลง
- [ ] ไม่มีภาพ/เพลงติดลิขสิทธิ์, license ระบุใน assets.md
