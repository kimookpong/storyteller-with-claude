# 15 · ภาพจริงจากการค้นคว้า (ขึ้นจอใน collage)

> ทำใน stage 2 คู่กับ `facts.md` · ใช้ในช็อต collage แบบ Vox (ภาพถ่ายเก่า เอกสาร แผนที่ โบราณวัตถุ ภูมิประเทศจริง) · ไม่บังคับ — เรื่องที่ไม่มีภาพจริงดี ๆ ข้ามได้
> สคริปต์: `python3 scripts/refs.py <slug>` (ปุ่ม “ดาวน์โหลด + ตรวจ license” ในหน้า ค้นคว้า) → `public/<slug>/ref/<id>.jpg` + `refs.lock.json`
> **Claude ไม่ตัดสิน license เอง** — `refs.py` อ่าน license จาก API ของแหล่งทุกครั้ง · **ผู้ใช้กด “ใช้รูปนี้” เอง** ก่อนรูปขึ้นในวิดีโอ (ห้ามแก้ `approved` ใน refs.lock.json)

## แหล่งที่รองรับ
| provider | ใส่อะไร | หมายเหตุ |
|---|---|---|
| `commons` | `"file": "File:ชื่อไฟล์.jpg"` ตรงตามหน้า Wikimedia Commons | แหล่งหลัก — ภาพจาก Wikipedia เกือบทั้งหมดอยู่ที่นี่ |
| `openverse` | `"key": "<uuid>"` จาก openverse.org | รวมภาพ CC จากหลายแหล่ง |
| `met` | `"key": "<objectID>"` จาก metmuseum.org | ใช้ได้เฉพาะชิ้นที่เป็น Open Access (CC0) |
ห้ามใช้: Google Images, ภาพข่าว, stock ที่มีลายน้ำ, ภาพจากโซเชียล, ภาพที่ไม่รู้ที่มา — ต่อให้ "หาได้ทั่วไป"

## `projects/<slug>/refs.json`
```json
{"refs": [
  {"id": "chedi-old-photo", "provider": "commons", "file": "File:Wat Phra Mahathat Nakhon Si Thammarat 1900s.jpg",
   "use": "onscreen", "factRef": "F21", "note": "พระธาตุในภาพถ่ายเก่า — ใช้คู่ S05-02"}
]}
```
- `id` a-z 0-9 - · 1 รูป 1 id · `factRef` = ข้อเท็จจริงที่รูปนี้ช่วยเล่า (ต้องมีใน facts.md)
- ชื่อไฟล์ Commons ต้องมาจากหน้าที่เปิดดูจริง (WebSearch/WebFetch หน้า Commons หรือ Wikipedia) — ห้ามเดาชื่อไฟล์
- **จำนวน:** ดูบรรทัด "ภาพจริง" ใน `npm run budget -- <slug>` — คิดจาก จำนวนช็อต × สัดส่วน collage/parallax ของสไตล์ × `refs` ใน `presets/styles/<style>.json` (สไตล์ภาพเก่าอย่าง retro-newsreel / archive-doc ใช้ภาพจริงมาก · kids-cartoon ไม่ใช้)
  - ค้น **ผู้สมัคร ~1.3 เท่า** ของที่จะใช้จริง (เผื่อ license ไม่ผ่าน / ผู้ใช้ไม่เลือก) · ภาพไม่ซ้ำไม่เกิน 30 (คลิปยาวใช้ภาพเดิมซ้ำได้ ≤ 2 ช็อต ครอปต่างกัน)
  - ตัวอย่าง: retro-newsreel 1 นาที ≈ ใช้ 5–10 ช็อต ค้น ~13 รูป · kurzgesagt-vox 3 นาที ≈ 6–11 ช็อต ค้น ~15 รูป
  - กระจายทุก beat/ยุค — **ยุคที่หาภาพ license ผ่านไม่ได้ ใช้ vector แทน ห้ามยัดภาพไม่ตรงเรื่องให้ครบจำนวน** · ภาพ "บรรยากาศ" (ไม่ใช่เหตุการณ์ที่พูด) ใช้ได้ถ้ามีป้ายบอกปี/สถานที่จริง

## license (refs.py ตัดสินจาก API)
| ผล | license | ใช้ได้ไหม |
|---|---|---|
| ✓ ok | Public domain · PDM · CC0 · CC BY | ใช้ได้ (CC BY ต้องมีเครดิต — ระบบใส่ให้) |
| ⚑ flag | CC BY-SA · Free Art License · GFDL อย่างเดียว · มีข้อจำกัดสิทธิ์บุคคล/เครื่องหมายการค้า | ใช้ได้ถ้าผู้ใช้ยอมรับ — ต้องมีเครดิต + license · ตรวจเงื่อนไข share-alike ก่อนหารายได้ |
| ✗ blocked | NC (ห้ามเชิงพาณิชย์) · ND (ห้ามดัดแปลง — ครอป/ใส่ tone ไม่ได้) · ไม่รู้ license | ใช้ไม่ได้ — validate เป็น error ถ้าอยู่ในช็อต |

## เนื้อหาที่ต้องระวัง (แม้ license ผ่าน)
- **ไม่ใช้ภาพบุคคลที่ระบุตัวได้ในยุคปัจจุบัน** (สิทธิ์ในภาพบุคคล) — ภาพเก่ามาก/ภาพวาดประวัติศาสตร์ใช้ได้
- ภาพศาสนา/พระพุทธรูป/สถานที่ศักดิ์สิทธิ์: ใช้อย่างสุภาพ ไม่ครอปตัดศีรษะ ไม่วางข้อความทับองค์พระ · ข้อห้ามใน brief (เช่น ไม่แสดงใบหน้าบุคคลศักดิ์สิทธิ์) ชนะเสมอ
- ภาพสงคราม/ศพ/ความรุนแรง: ไม่ใช้
- ภาพต้องตรงกับสิ่งที่พูด — ห้ามใช้ภาพสถานที่อื่นแทนแล้วทำเหมือนเป็นที่เดียวกัน (ถ้าเป็นภาพ "ตัวอย่าง" ให้บอกในบท/ป้าย)

## ใช้ในช็อต (stage 5)
```json
{"id": "photo", "asset": "ref:chedi-old-photo|chedi-bell", "style": "collage", "z": 1000, "x": 0, "y": -40, "w": 620, "rot": -3, "anim": "stop-motion"}
```
- รูปแบบ `ref:<id>|<vector-fallback>` เหมือนภาพ AI — ก่อนอนุมัติ/ดาวน์โหลด วิดีโอใช้ vector ไปก่อน
- ระบบวาดเป็นภาพถ่ายติดกระดาษ (ขอบขาว + เงา + tone ตามยุค) — ไม่ตัดพื้นหลัง ไม่ดัดแปลงเนื้อภาพนอกจาก tone/ครอปตามกรอบ
- ขนาดบนจอไม่เกิน ~70% ของความกว้างเฟรม (ความละเอียดรูปมักจำกัด) · ใช้ในช็อต `collage` หรือ `parallax` ที่รูปอยู่ชั้นกลาง
- **เครดิตอัตโนมัติ:** บรรทัด "ที่มา" มุมจอแสดง `ภาพ: ผู้สร้าง · license` ทุกช็อตที่ใช้ และ `{{sources}}` ใน post.json มีหัวข้อ "ภาพประกอบ" (ชื่อภาพ ผู้สร้าง license ลิงก์)
- บันทึกใน `assets.md` หมวด "ภาพจริง" (id · แหล่ง · license · ใช้ในช็อต)

## เครือข่าย
`refs.py` ต้องเข้าถึง commons.wikimedia.org · upload.wikimedia.org · api.openverse.org · collectionapi.metmuseum.org · images.metmuseum.org — รันบนเครื่องผู้ใช้ผ่าน HistoryTeller (ถ้าเน็ตถูกบล็อก ให้บอกผู้ใช้ อย่าหาทางอ้อม)
