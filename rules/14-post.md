# 14 · Post — ข้อความโพสต์ลงแพลตฟอร์ม (stage 11)

> ทำหลังปก (stage 10) — ดีที่สุดคือหลังมีเสียงพากย์แล้ว (เวลาในบทคลิปจะตรง) · ข้อจำกัดของแต่ละแพลตฟอร์มอยู่ใน `presets/platforms.json` (แก้ได้เมื่อแพลตฟอร์มเปลี่ยน)
> ก่อนเขียน: `node scripts/post.mjs <slug> --kit` → format, ความยาวจริง, แพลตฟอร์มที่เหมาะ, ปก, เวลาเริ่มซีน, จำนวนแหล่งอ้างอิง
> หลังเขียน: `node scripts/post.mjs <slug>` ต้องผ่าน (ไม่มี ✗) → ได้ `out/<slug>-post.md` · ตั้ง stage `post` เป็น `review` (ห้ามอนุมัติเอง)

## แพลตฟอร์มตาม format
| format | เขียนให้ |
|---|---|
| `landscape-16x9` | YouTube · Facebook · X |
| `portrait-9x16` | TikTok · YouTube (Shorts) · Instagram Reels · Facebook (Reels) · X |

## `projects/<slug>/post.json`
```json
{
  "aiDisclosure": false,
  "notes": "เหตุผลสั้น ๆ เช่น ภาพเป็นการ์ตูน ไม่ใช่ภาพสมจริง",
  "chapters": {"S01": "เปิดเรื่อง", "S03": "ต้นกำเนิด", "S05": "จุดพลิก"},
  "credit": "บรรทัดเครดิตเพิ่ม (ถ้ามี)",
  "platforms": {
    "youtube":   {"title": "…", "description": "2 บรรทัดแรกดึงคน\n\n{{chapters}}\n\nที่มา\n{{sources}}\n\n{{credit}}", "tags": ["…"], "hashtags": ["…"], "pinnedComment": "…", "cover": "A"},
    "tiktok":    {"caption": "…", "hashtags": ["…"], "cover": "A"},
    "instagram": {"caption": "…\n\nที่มา: …", "hashtags": ["…"]},
    "facebook":  {"text": "…\n\nที่มา\n{{sources}}"},
    "x":         {"text": "…", "thread": ["…", "…"]}
  }
}
```
- **ตัวแทนที่ระบบใส่ให้** (ห้ามพิมพ์เอง): `{{chapters}}` บทคลิปจากเวลาจริง (YouTube แนวนอนเท่านั้น · ต้อง ≥ 3 บท บทละ ≥ 10 วิ ไม่งั้นว่าง) · `{{sources}}` รายการแหล่งจาก `facts.md` (เฉพาะที่มีลิงก์) · `{{credit}}` จาก `presets/channel.json` + `credit` · `{{hashtags}}` วางแฮชแท็กตรงนั้น (ไม่ใส่ = ต่อท้ายให้เอง)
- `chapters` ใส่ชื่อบทเฉพาะซีนที่เป็นจุดเปลี่ยน (คีย์ = id ซีน) · ชื่อบทสั้น ≤ 30 ตัวอักษร
- `hashtags` ใส่ไม่มี `#` ก็ได้ · ไม่มีช่องว่างในแท็ก
- `cover` = ปกที่แนะนำให้ใช้บนแพลตฟอร์มนั้น (id จาก `covers`)

## หลักการเขียน (ทุกแพลตฟอร์ม)
1. **ถูกต้องก่อน** — ทุกตัวเลข/ข้อเท็จจริงต้องมีใน `facts.md` เหมือนบท (rule 00) · ความมั่นใจกลาง/ต่ำใช้คำกันแบบเดียวกับบท ("ราว", "ตำนานเล่าว่า")
2. **ต่อจาก hook ไม่ใช่ซ้ำ hook** — ประโยคแรกเพิ่มความอยากรู้ ไม่สปอยล์คำตอบใน payoff (ถามคำถามเดิมด้วยคำใหม่ได้)
3. **เสียงเดียวกับผู้เล่า** — สรรพนาม/คำลงท้ายตาม persona (`presets/voices/<voice>.md`) แต่อ่านเป็นตัวหนังสือ: ประโยคสั้น เว้นบรรทัดบ่อย · อีโมจิ ≤ 2 ต่อโพสต์
4. **ไม่หลอกคลิก** — ชื่อคลิป/แคปชันต้องตรงกับเนื้อหา ห้ามตัวเลขหรือคำที่ไม่มีในคลิป · ห้ามพาดพิงบุคคล/ศาสนาเชิงลบ
5. **ที่มา + เครดิต** — YouTube/Facebook ใส่ `{{sources}}` ครบ · TikTok/Instagram/X ใส่ที่มาย่อ 1–2 แหล่งหลัก หรือบอก "ที่มาอยู่ในคอมเมนต์/YouTube"
6. **แฮชแท็ก** เฉพาะเรื่อง ภาษาไทยปนอังกฤษได้ ตามจำนวนใน platforms.json (Instagram สูงสุด 5 · TikTok 3–5 · YouTube 2–3 · X 0–2) · ห้ามแท็กยอดนิยมที่ไม่เกี่ยว
7. **ชวนคุยได้ ห้ามขอยอด** — ปิดด้วยคำถามให้คอมเมนต์ได้ แต่ถ้า persona ห้าม CTA (เช่น `fast-hype`) ห้าม "กดไลก์/ติดตาม/แชร์"

## รายแพลตฟอร์ม
| | ความยาว | สิ่งที่ต้องมี |
|---|---|---|
| YouTube ชื่อคลิป | ≤ 100 (แนะนำ 30–70) | คำถาม/ตัวเลขจาก hook · คำค้นหลักอยู่ต้นชื่อ · ไม่ใส่แฮชแท็กในชื่อ |
| YouTube คำอธิบาย | ≤ 5,000 | 2 บรรทัดแรกขายเรื่อง → `{{chapters}}` → ที่มา `{{sources}}` → `{{credit}}` · แท็ก ≤ 500 ตัวอักษรรวม |
| TikTok | ≤ 4,000 (แนะนำ 60–300) | 1–3 บรรทัด + คำถามชวนคอมเมนต์ + แฮชแท็ก 3–5 |
| Instagram Reels | ≤ 2,200 | 125 ตัวอักษรแรกต้องครบความ · แฮชแท็ก ≤ 5 |
| Facebook | ยาวได้ (แนะนำ 80–600) | เล่าสั้นเป็นย่อหน้า 2–4 ย่อหน้า + ที่มา |
| X | ≤ 280 ต่อโพสต์ | ตัวเลขแรงสุดก่อน · `thread` ต่อได้ 2–4 โพสต์ (เรื่องละ 1 ข้อ) |

## ป้ายเนื้อหา AI (`aiDisclosure`)
- `true` เมื่อมีภาพ/เสียงสังเคราะห์ที่ **ดูสมจริง** จนคนอาจเข้าใจว่าเป็นภาพ/เหตุการณ์/บุคคลจริง (YouTube และ TikTok มีช่องให้ติ๊กตอนอัปโหลด)
- ภาพการ์ตูน/infographic + เสียง TTS บรรยายทั่วไป โดยปกติไม่ต้องติด — แต่เขียนเหตุผลใน `notes` และให้ผู้ใช้ตัดสิน (นโยบายแพลตฟอร์มเปลี่ยนได้)
