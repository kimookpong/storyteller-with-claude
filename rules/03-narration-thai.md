# 03 · Narration — ภาษาบรรยายไทย

> **บุคลิกผู้เล่า** (สรรพนาม คำลงท้าย ระดับภาษา คำต้องห้าม) มาจาก voice preset ของโปรเจกต์:
> `projects/<slug>/settings.json` → `voice` → อ่าน **`presets/voices/<voice>.md`** ก่อนเขียนบททุกครั้ง
> กฎในไฟล์นี้ใช้กับทุก voice · ถ้าขัดกับ persona ให้ persona ชนะ
> validate ตรวจคำต้องห้าม / คำสุภาพ (ครับ/ค่ะ) / คำจำกัดจำนวน ตาม `persona` ใน `presets/voices/<voice>.json`

| voice preset | บุคลิกย่อ |
|---|---|
| `friend-sleepy-male` | เพื่อนชายเล่าตอนดึก อบอุ่น ช้า ง่วงนิด ๆ (ค่าเริ่มต้น · coffee-world) |
| `friend-bright-female` | เพื่อนหญิงสดใส ขี้สงสัย |
| `doc-narrator` | ผู้บรรยายสารคดี ทุ้ม นิ่ง กึ่งทางการ |
| `fast-hype` | เล่าเร็ว รัว ๆ แบบคลิปสั้น (ประโยค ≤ 12 พยางค์, ไม่ทักทาย/ไม่ CTA) — เหมาะคลิป ≤ 2 นาที |
| `doc-narrator-female` | ผู้บรรยายหญิง อบอุ่น กึ่งทางการ ไม่มีคำลงท้าย |
| `teacher-kind` | ครูใจดี คำง่าย ถาม-ตอบ เปรียบของใกล้ตัว — เด็ก/ผู้เริ่มต้น |
| `elder-storyteller` | ผู้เฒ่าเล่าตำนาน ช้า ทุ้ม ข้างกองไฟ — ตำนาน/โบราณ (ตัวเลขน้อย) |
| `news-anchor` | ผู้ประกาศข่าว เป็นกลาง กระชับ ไม่มีคำลงท้าย — เหตุการณ์/การเมือง/เศรษฐกิจ |

> `persona.banned` ตรวจแบบ substring — ห้ามใส่คำสั้นที่อยู่ในคำอื่น (อะ→อะไร, นะ→ชนะ, คะ→คะแนน) ให้เขียนไว้ใน `.md` แทน

## ภาษา (ทุก voice)
- ประโยคสั้น: ส่วนใหญ่ ≤ 20 พยางค์, 1 ประโยค 1 ไอเดีย
- คำอังกฤษ/ศัพท์เทคนิค: ใช้เมื่อคนไทยพูดกันจริง และแปลไทยกำกับครั้งแรก
- คำลงท้าย (ถ้า persona มี): ≤ 1 คำต่อประโยค และไม่ซ้ำคำเดิม 3 ประโยคติด

## การอธิบายแบบ Kurzgesagt ในปากคนไทย
- เปรียบเทียบสเกลกับของใกล้ตัว: สนามฟุตบอล, รถไฟฟ้า BTS, ข้าวกะเพรา 1 จาน, ตึกใบหยก
- ตัวเลขใหญ่ → แปลงเป็นภาพที่นึกออก ("ถ้าเอามาเรียงกันจะยาวจากกรุงเทพฯ ไปเชียงใหม่")
- มุกได้ แต่ต้องเป็นมุกจากเนื้อเรื่อง ห้ามมุกที่ต้องรู้บริบทนอกเรื่อง / เหยียดกลุ่มคน

## ความถูกต้อง
- ทุกตัวเลขต้องมีใน `facts.md`, ปัดเลขให้พูดง่าย ("เกือบ ๆ แปดพันล้านคน") แต่ห้ามบิดความหมาย
- ความเชื่อ/ตำนาน ต้องใส่คำกัน ("เขาเล่ากันว่า")

## ซับอังกฤษ (`voEn`) — ทำใน stage 4 พร้อมบท
- ทุกซีนมี `voEn` เมื่อ settings `subtitles` เป็น `th+en` หรือ `en` (validate เป็น error ถ้าขาด) · ทำไว้ล่วงหน้าได้เสมอ (ได้ไฟล์ `.en.srt`)
- **cue marker ชุดเดียวกับ `vo` ตรงตำแหน่งเดียวกัน** → ซับอังกฤษตรงจังหวะเสียงไทยเอง
- แปลความหมาย ไม่แปลคำต่อคำ · สั้นกระชับ (ช่วงละ ≤ 170 ตัวอักษร) · คำลงท้าย (นะ/อะ/ปะ) ไม่ต้องแปล · ชื่อเฉพาะสะกดสากล (Jebel Irhoud, Atrahasis) · ตัวเลขใช้หน่วยสากล (4.54 billion, 11:59:54 PM)
- ความเชื่อ/คัมภีร์ใช้คำกันแบบเดียวกับบทไทย ("Genesis says…", "The Quran says…")
- ใน `script.md` ใส่บรรทัด `**EN:**` ใต้ `**VO:**` ของแต่ละซีน

## งบคำ
ความยาวบทต้องอยู่ในงบของโปรเจกต์ (rule 01 · `npm run budget -- <slug>`) — งบคำนวณจากอัตราพูดของ voice ที่เลือก
เปลี่ยน voice = อัตราพูดเปลี่ยน = งบเปลี่ยน

## รูปแบบในสคริปต์ (สำหรับ TTS)
- `vo` = ข้อความที่แสดงเป็น subtitle
- `voTTS` = ข้อความที่ส่ง TTS: ตัวเลขเขียนเป็นคำอ่าน, ตัวย่อ/ชื่อต่างประเทศสะกดตามเสียง, ใส่ `…` เพื่อเว้นจังหวะ
- `…` = หยุดสั้น (~0.3s), บรรทัดว่าง = หยุดยาว (`paraGapMs` ของ voice) ใช้ก่อน reveal
- TTS: **Google Gemini TTS ผ่าน OpenRouter** — model / voice / style prompt มาจาก voice preset (`tts`) ไม่ใช่ SSML
  (`.env` `TTS_*` ใช้เฉพาะเมื่อไม่มี settings)
- เลือกเสียง: `python scripts/tts.py --audition --slug <slug>` (หรือปุ่ม "ลองเสียง" ในหน้า Settings) → ฟังใน `out/audition/<voice>/` แล้วตั้ง `overrides.voice.tts.voice`
- สร้างเสียง: `python scripts/tts.py projects/<slug>/shots.json` → ถ้าคำไหนอ่านผิด แก้ที่ `voTTS` แล้วรันใหม่ (ช่วงที่ไม่ได้แก้ใช้ cache ไม่เสียเงินซ้ำ)
- **เปลี่ยน voice/style prompt = cache ใช้ไม่ได้ → สร้างเสียงใหม่ทั้งเรื่อง (เสียเงินเต็ม)**
- `tts.gapMs` / `paraGapMs` / `trimKeepMs` = ช่องว่างระหว่างช่วง / ก่อนย่อหน้า / เงียบที่เก็บหัวท้าย (เสียงเร็วใช้ 40 / 220 / 15)
- `tts.tempo` (0.8–1.3, ปกติ 1.0) = เร่งทั้งซีนด้วย ffmpeg หลังต่อเสียง (ไม่เสีย cache) — **เป็นสไตล์ ไม่ใช่ทางแก้บทยาว** · งบคิดจาก `charsPerSec × tempo`
