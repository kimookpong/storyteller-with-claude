# 06 · Camera — 2.5D Parallax + Depth of Field

## เมื่อไหร่ใช้
- สัดส่วนช็อตทั้งเรื่อง: **2.5D parallax 30–40%** · flat vector motion ~30% · collage 20–30% · data/type 10–15%
- บังคับใช้: Hook, ช็อตเปิดยุคใหม่, data moment ใหญ่, ช็อตสุดท้าย
- ห้ามใช้ติดกันเกิน 3 ช็อต (คนดูเมา และเสียความพิเศษ)

## Layer stack (มาตรฐาน)
| Layer | `z` (depth) | หน้าที่ | Blur เมื่อโฟกัสที่ subject |
|-------|------------|--------|----------------------|
| `fg` | 400–600 | ใบไม้/กระดาษ/ฝุ่น เฉียดหน้ากล้อง | แรง (8–14px) |
| `subject` | 1000 | พระเอกของช็อต | 0 |
| `mg` | 1400–2000 | บริบท | 2–5px |
| `bg` | 2500–4000 | ท้องฟ้า/ผนัง/texture ยุค | 5–10px |
- ต้องมี ≥ 3 layer ถึงจะนับเป็น 2.5D; asset ต้องตัดพื้นหลัง (PNG/SVG โปร่งใส) และ **ขยายขอบเผื่อ 15–20%** กันขอบโผล่เวลากล้องขยับ

## โมเดลกล้อง (ใช้สูตรเดียวทั้งโปรเจกต์)
```
F = 1000                         // focal; layer z=1000 → scale 1 ตอนกล้องอยู่ที่ 0
d      = layer.z - cam.z          // ระยะจากกล้อง (ต้อง > 50)
scale  = F / d
x_scr  = (layer.x - cam.x) * scale + W/2
y_scr  = (layer.y - cam.y) * scale + H/2
dFocus = focus.z - cam.z
blurPx = min(MAX_BLUR, APERTURE * |d - dFocus| / d)   // APERTURE≈18, MAX_BLUR=14
```

## Camera moves ที่อนุญาต
| move | ใช้เมื่อ | ระยะทั่วไป |
|------|--------|-----------|
| `push-in` | เข้าหารายละเอียด/ความตึงเครียด | cam.z 0→150–300 |
| `pull-out` | reveal สเกล "จริง ๆ มันใหญ่กว่านั้น" | cam.z 0→−400 |
| `truck` (แพนข้าง) | เดินผ่าน timeline/ขบวน | cam.x ±200–600 |
| `crane` | ขึ้น/ลงระหว่างชั้นข้อมูล | cam.y ±150–400 |
| `drift` | ช็อตพูดยาว ต้องมีชีวิต | cam.x/y ±20–40 |
| `fly-through` | ทะลุ layer เข้าซีนใหม่ (transition) | cam.z ทะลุ fg |
- 1 ช็อต = 1 move หลัก (+ drift ได้)
- Easing: `inOutCubic` เป็นค่าเริ่ม, reveal ใช้ `outExpo`, ห้าม linear ยกเว้น drift
- ความเร็วสอดคล้องกับเสียง: เสียงชิล → move ช้า-นุ่ม แต่ **ต้องเห็นชัด** (ระยะไม่ต่ำกว่าตาราง)

## DOF
- ค่าเริ่ม: โฟกัสที่ `subject`
- **Rack focus**: เปลี่ยนโฟกัสตรงคำที่บทพูดถึงอีกสิ่ง (ผูกกับ cue ใน VO) ใช้ 10–18 เฟรม
- ตัวหนังสือ/ตัวเลขที่ต้องอ่าน **ห้ามเบลอ** — วางใน layer ที่ blur=0 หรือเป็น overlay 2D
- เพิ่ม bokeh/ฝุ่นลอยใน `fg` ได้เพื่อความลึก (opacity ≤ 40%)
