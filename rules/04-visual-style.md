# 04 · Visual Style — Kurzgesagt × Vox Collage

> ไฟล์นี้คือภาษาภาพของ style `kurzgesagt-vox` (ค่าเริ่มต้น) · style อื่นใช้หลักเดียวกันแต่ปรับสัดส่วน/จังหวะตาม `presets/styles/<style>.json`
> `archive-doc`: collage/เอกสารเป็นพระเอก กล้อง drift ช้า · `map-explainer`: แผนที่/กราฟเป็นพระเอก คั่นด้วย vector
> `cinematic-parallax`: parallax+DOF 45–60% ตัดช้า คู่กับภาพ AI · `retro-newsreel`: collage หนังสือพิมพ์/ฟิล์ม ยุค 1800s–ปัจจุบัน · `kids-cartoon`: vector สีสด เด้ง ข้อมูลน้อย · `minimal-data`: ตัวเลข/กราฟ 50–70% · `shorts-punch`: คลิปสั้นแนวตั้ง

## แบ่งหน้าที่ของสองสไตล์ (สำคัญที่สุด)
| | Kurzgesagt (vector) | Vox Collage |
|---|---|---|
| ใช้กับ | ตัวละคร, กลไก, แผนภาพ, ข้อมูล, "ปัจจุบัน/อนาคต" | บริบทประวัติศาสตร์, หลักฐาน, ภาพจริง, "อดีต" |
| ลักษณะ | flat vector, shape กลมมน, ไม่มี outline, gradient อ่อน, glow บนพื้นเข้ม | ภาพถ่าย/เอกสารตัดขอบกระดาษ, halftone, เทปกาว, ปากกาวง/ขีดเส้นใต้, highlighter |
| เคลื่อนไหว | spring/bounce นุ่ม, pop-in, loop เล็ก ๆ | stop-motion 12fps, กระดาษสั่นเล็กน้อย, slide-in แบบวางกระดาษ |

**กฎผสม:** 1 เฟรมมี "พระเอก" ได้สไตล์เดียว — ถ้า subject เป็น vector, collage อยู่ BG/FG ได้ และกลับกัน
ห้ามให้สองสไตล์แย่ง focus กัน (DOF ช่วยแยก — ดู 06)

## Character anchor
- มีตัวละครหลัก/สัญลักษณ์ 1 ตัว สไตล์ Kurzgesagt ที่อยู่ทั้งเรื่อง (ออกแบบเองใหม่ ห้ามลอกตัวละครของช่องใด ๆ)
- ข้ามยุคได้ แต่ตัวละครนี้ **ไม่เปลี่ยนสไตล์** — ได้แค่ overlay texture ของยุคบาง ๆ (≤ 25% opacity)

## Palette (token)
```
--bg-deep:   #0E1A2B   (พื้นหลังหลัก โทนน้ำเงินเข้ม)
--bg-mid:    #1C3350
--accent-1:  #FF6B4A   (ส้มแดง — สิ่งสำคัญ/อันตราย)
--accent-2:  #FFC94A   (เหลือง — ไฮไลต์, ตัวเลข)
--accent-3:  #3FD6C6   (เขียวฟ้า — บวก/วิทยาศาสตร์)
--accent-4:  #B28CFF   (ม่วง — อนาคต/นามธรรม)
--paper:     #F2E8D5   (กระดาษ collage)
--ink:       #1A1A1A   (หมึก/ปากกาวง)
--marker:    #E8413C   (ปากกาแดงวง collage)
```
- 1 เฟรมใช้ accent ≤ 2 สี
- palette ถูก "tint" ตามยุคได้ (ดู 05) แต่ accent-2 (ตัวเลข) คงที่ทั้งเรื่อง

## Composition
- Rule of thirds / center สำหรับ reveal, พื้นที่ว่างเยอะ (negative space) แบบ Kurzgesagt
- ภาพต้องอ่านรู้เรื่องใน 1 วินาทีแม้ปิดเสียง
- Collage: เลเยอร์ซ้อน 3–6 ชิ้น, หมุนเอียง ±2–6°, เงา drop shadow นุ่ม (กระดาษลอย)

## ห้าม
- ภาพ stock ที่มีลายน้ำ/โลโก้แบรนด์, ภาพบุคคลจริงที่ไม่มีสิทธิ์ใช้
- ลอกตัวละคร/นก/สัญลักษณ์ของ Kurzgesagt หรือกราฟิกของ Vox โดยตรง — เอาแค่ "หลักการ" สไตล์


## vector หรือ PNG (ตัดสินใน stage 6)
รัน `node scripts/asset-plan.mjs <slug>` (หรือดูตาราง "คำแนะนำ vector / PNG" ในหน้า Asset list) — ระบบคิดจากการใช้งานจริงใน shots.json แล้วเสนอ Claude ตัดสินใน `assets.md` พร้อมเหตุผลเมื่อไม่ตามคำแนะนำ
| เงื่อนไข | ผล |
|---|---|
| ข้อความ ตัวเลข กราฟ แผนที่ ไอคอน ตรายาง หน้าจอแอป · บุคคลที่ห้ามมีใบหน้า · ลายอักษร (`presets/asset-hints.json` → vectorOnly) | **vector เสมอ** |
| props ที่ขยับเป็นส่วน (grow, fall, wave, from/to …) | vector ในช็อตนั้น (ช็อตที่นิ่งใช้ PNG ได้) |
| กว้าง < 15% ของเฟรม | vector (คนดูแยกไม่ออก ไม่คุ้มเงิน) |
| ฉากหลังเต็มจอ (`cover`) · พระเอกของเฟรม ≥ 35% · ใช้ ≥ 3 ช็อต · อยู่บนปก | คะแนนไปทาง **PNG** (style `render: vector` หัก 1 · `hybrid`/`image` บวก 1) |
| กล้องซูมจนต้องการ > ~1,700px | ระวัง: รูป AI ~1,344px อาจไม่คม → vector หรือ plate ที่ไม่ซูมมาก |
- PNG ทุกชิ้นยังต้องมี vector สำรอง (`img:<id>|<vector>`) · ท่า/สีหน้าต่างกัน = รูปต่างกัน (นับใน "แบบ")

## ภาพจริงจากการค้นคว้า
ภาพถ่าย/เอกสาร/แผนที่เก่าที่มีสิทธิ์ใช้ → ดู `rules/15-research-images.md` (ใช้ใน collage: `ref:<id>|<vector>`)

## ภาพจาก AI (แบบผสม — `images.json`)
- **อะไรเป็นรูป AI:** ฉากหลัง (plate), ตัวละคร, สิ่งของ, ฉากสำคัญ · **อะไรยังเป็น vector:** ข้อมูล/กราฟ/แผนที่/ตัวหนังสือ/ตัวเลข/นาฬิกา/ลูกศร/ตรายาง และทุกอย่างที่ต้องขยับเป็นส่วน ๆ
- **ห้ามตัวหนังสือในรูป** (ระบบต่อท้าย prompt ให้เอง) — ข้อความใส่ด้วย Remotion เสมอ
- สไตล์รวมมาจาก style preset → `image.prompt` (บรรยายลักษณะ ห้ามใส่ชื่อช่อง/ศิลปิน) + โทนตามยุค (imagegen.py ใส่ให้จาก `era` ของซีนที่ใช้รูป)
- `kind`: `plate` = ฉากเต็มเฟรม (layer `cover: true`) · `cutout` = พื้นโปร่งใส (พื้นเขียวแล้วลบด้วย ffmpeg หรือโมเดลที่ทำโปร่งใสได้)
- **ตัวละคร anchor:** สร้าง `<name>-sheet` ก่อน (ผู้ใช้เลือก) แล้วทุกท่า/สีหน้าใส่ `"refs": ["<name>-sheet"]` · สีหน้าต่างกัน = รูปต่างกัน (`clay-buddy-happy`, `-wow` …)
- parallax: สร้างแยกชั้น (plate ฉากหลัง + cutout พระเอก + cutout ฉากหน้า) — ไม่ตัดจากภาพเดียว
- ใน shots.json ใช้ `"asset": "img:<id>|<vector-fallback>"` → ก่อนเลือกรูปจะใช้ vector เดิม (ไม่มีกล่องเหลือง) · ไม่มี fallback ได้ แต่จะขึ้นกล่องชื่อจนกว่าจะเลือก
- เรื่องศาสนา/บุคคลจริง: prompt ห้ามใบหน้า และ **ผู้ใช้ตรวจทุกรูปก่อนเลือก** (ไม่มีเลือกอัตโนมัติ) · ภาพสไตล์การ์ตูนไม่ต้องติดป้าย AI บน YouTube แต่ห้ามทำภาพสมจริงของเหตุการณ์ประวัติศาสตร์
- บันทึกที่มาใน `assets.md`: model + วันที่ (จาก `images.lock.json`) + ตรวจเงื่อนไขเชิงพาณิชย์ของโมเดล
