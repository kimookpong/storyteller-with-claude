# 12 · Cover (ปก YouTube)

ปกคือ "ช็อตที่ 0" — คนตัดสินใจกดดูจากภาพขนาด ~320×180 บนมือถือภายในครึ่งวินาที
ปกใช้ asset/สไตล์/palette ชุดเดียวกับในคลิป (ห้ามสัญญาภาพที่คลิปไม่มี)

## สเปก
- ออกแบบที่ 1920×1080 → export **1280×720 JPEG ≤ 2MB** (`npm run cover` → `out/cover/<slug>-<id>.jpg`)
- มีภาพเช็กมือถือ `out/cover/<slug>-<id>-mobile.png` (320×180) — **ต้องอ่านหัวข้อออกที่ขนาดนี้**
- ทำ **2–3 แบบ** (`id: A, B, C`) ต่างกันที่ "มุม" ไม่ใช่แค่สี — ไว้ A/B test (YouTube Test & Compare)

## แนวตั้ง (TikTok / Reels / Shorts)
- ปก = ภาพ 1080×1920 (`npm run cover` ได้ .jpg เต็มขนาด) — TikTok ให้เลือกเฟรม/อัปโหลดรูปปก
- หน้าโปรไฟล์ตัดเป็น **3:4 กลางภาพ** → หัวข้ออยู่กลางจอ (ระบบวางที่ 24–54% ของความสูง) ไม่ใช้ `side` · พระเอกอยู่บน/ล่างหัวข้อ
- หัวข้อ ≤ 2 บรรทัด บรรทัดละ ≤ 8 ตัวอักษร (จอแคบกว่า)

## องค์ประกอบ (สูตรเดียวทั้งช่อง)
| ส่วน | กติกา |
|------|------|
| พระเอก | 1 อย่าง ใหญ่ ≥ 35% ของเฟรม — ตัวละคร anchor ที่มีสีหน้า (sly / wow) ดีสุด |
| หัวข้อ | ≤ 2 บรรทัด, บรรทัดละ ≤ 10 ตัวอักษร (ไม่นับสระบน/ล่าง), รวม ≤ 18 — Kanit 700 |
| ไฮไลต์ | ครอบคำที่ "ขาย" ด้วย `*คำ*` → สี accent-2 ได้ 1 จุด |
| kicker | (ไม่บังคับ) ป้ายเล็กสีส้มแดง บอกความขัดแย้ง/ความแปลก |
| note | (ไม่บังคับ) ลายมือปากกาแดง ≤ 3 คำ |
| ฝั่ง | ตัวหนังสือฝั่งหนึ่ง พระเอกอีกฝั่ง (`side`) — ระบบใส่แถบมืด (scrim) หลังตัวหนังสือให้เอง |

## เนื้อหา
- หัวข้อ **เสริม** ชื่อคลิป ไม่ซ้ำคำ (ชื่อคลิป = คำถาม, ปก = ความขัดแย้ง/ผลลัพธ์)
- ตัวเลข/ปี บนปกต้องมี `sourceRef` ใน `facts.md` เหมือนในคลิป (rule 07) — ห้ามปกเกินจริงหรือหลอกคลิก
- ใช้ era texture ของยุคที่ปกเล่า ได้ แต่ตัวหนังสือต้องอยู่เหนือ texture และคมเสมอ

## ห้าม
- วางของสำคัญ **มุมขวาล่าง** (YouTube แปะเวลาคลิปทับ) และขอบ 5% รอบเฟรม
- ตัวหนังสือบาง/เล็กกว่า 120px (ที่ 1920), เกิน 3 สีในตัวหนังสือ, ลูกศร/วงแดงเกิน 1 จุด
- โลโก้แบรนด์ ภาพคนจริงที่ไม่มีสิทธิ์ ตัวละครของช่องอื่น (rule 04)

## Schema (`covers` ใน shots.json — ดู `CoverSpec` ใน src/types.ts)
```json
"covers": [{
  "id": "A", "era": "present", "kind": "parallax", "focus": "bean", "side": "left",
  "title": "กาแฟ\n*ยึดโลก*", "kicker": "เคยโดนสั่งห้าม!", "note": "ได้ไง?!", "noteAt": [1590, 150],
  "layers": [ …เหมือน layer ของช็อต (rule 09); กล้องนิ่ง, DOF ตาม focus… ]
}]
```
- `at` (default 2.5s) = เวลาที่หยุดภาพ ให้ anim pop/drop เล่นจบก่อน
- ปรับเร็ว: Remotion Studio → composition **cover** → แก้ props `coverId` แล้วดูสด
